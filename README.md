# Python CSV Employee Management

## About the Project
This is a beginner-level Python project that demonstrates how to store and retrieve employee information using CSV files.

## Features
- Create an employee CSV file.
- Store employee names, salaries, and departments.
- Write records using `csv.DictWriter()`.
- Read records using `csv.DictReader()`.

## Technologies Used
- Python
- CSV Module
- File Handling
- Dictionaries

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

```bash
python employee_management.py
```

## Learning Outcome
This project helped me understand CSV file handling, dictionaries, and reading and writing structured data in Python.
